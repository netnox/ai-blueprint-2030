# LLM 위키 — 한 달 뒤에 붙인다

세팅 직후에는 LLM 위키를 붙이지 않습니다. 한 달쯤 뒤에 붙입니다.

이것을 한 달 뒤로 미뤘습니다. 지도는 그릴 땅이 있어야 그립니다. 노트가 적을 때 만들면 빈 지도입니다.

## 왜 한 달 뒤인가

개념 노트와 슬립박스가 자리를 잡고, 행동 · 상태가 정의된 다음에야 지도에 담을 것이 있습니다.

## 어떻게 붙이나

Claude Code에게 이렇게 말합니다.

LLM 위키 붙여 줘. 볼트는 (내 볼트 경로)

또는 `palantir/`의 안내를 따릅니다.

## 사용 예

노트끼리의 연결(어느 노트에서 갈라져 나왔나, 어디에 링크되나)을 찾을 때 씁니다.

「」 안은 원문의 말 그대로입니다. [3편](https://youtu.be/Pn7M9dvde4A)은 유튜브 영상입니다. 나머지 문장은 설명을 위해 정리한 것입니다.
