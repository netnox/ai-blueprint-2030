**나중에 쓸 바깥 자료를 둡니다.** 「Resources에서는 관심 주제 참고 자료 나중에 쓸 정보들을 모아보는 거죠」 (3편 08:08)

옷장으로 치면 이렇습니다. 「Resources : 정장, 등산복, 수영복. 지금은 아니지만 언젠가 확실히」 (블로그 21번)

## 무엇을 넣나요

내 볼트에는 이런 자료 폴더가 있습니다. 책과 영상에서 뽑은 소스, 독서 기록, 도구와 방법론, 조사, 콘텐츠 제작 자료.

세팅 때 들어오는 것:
- `다시_묻기/` — 궁금한 것 열일곱 답 파일
- `세팅/` — 옵시디언 · VS Code · 검색 엔진 · LLM 위키 · MCP 서버. 실제로 쓰는 세팅 다섯 장입니다.
