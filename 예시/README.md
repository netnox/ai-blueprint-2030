# 예시 · 저는 이렇게 씁니다

제 볼트에서 실제 노트 여덟 장을 옮겨 왔습니다. **참고용 실물 예시**입니다. 문장 속의 이름·날짜·관찰은 원작 노트 그대로이며, 사용자의 볼트 규칙과 섞지 않습니다.

## 읽는 법

- 「」 안 · 형광펜 · 일간과 메모 본문 = 작성자 글
- 💡 · (B) = Claude가 쓴 것
- `[[ ]]` 링크 = 공개하지 않은 노트라 여기서는 열리지 않을 수 있습니다

## 답 파일이 가리키는 예시

`다시_묻기/`의 답 파일 가운데 예시를 가리키는 것만 적었습니다.
