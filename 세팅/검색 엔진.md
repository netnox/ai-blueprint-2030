# 검색 엔진

볼트 전체를 빠르게 검색하는 도구입니다. MCP 서버로 Claude Code에 붙입니다.

## 언제

START.md로 세팅할 때는 깔지 않습니다. 1주쯤 뒤에 Claude Code에게 [검색/README.md](https://github.com/netnox/bottom-up/blob/main/%EA%B2%80%EC%83%89/README.md)를 주고 붙여 달라고 하면 Claude가 설치합니다.

## 왜

옵시디언 검색만으로도 되지만, Claude가 볼트 내용을 직접 찾아 답할 때 필요합니다.

## 어떻게

`검색/README.md`와 `palantir/`의 스크립트를 따릅니다.
