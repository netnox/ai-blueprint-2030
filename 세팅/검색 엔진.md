# 검색 엔진

볼트 전체를 빠르게 검색하는 도구입니다. MCP 서버로 Claude Code에 붙입니다.

## 언제

START로 세팅할 때는 깔지 않습니다. **1주쯤 뒤**에 붙입니다.

## 왜

옵시디언 글자 검색만으로도 되지만, Claude가 **뜻으로** 가까운 노트를 찾을 때 필요합니다. 노트는 자기 컴퓨터 안에서 동작하는 구성을 기준으로 합니다.

## 어떻게 (한 줄)

```
https://github.com/netnox/bottom-up 의 검색/README.md대로 검색 엔진 붙여 줘. 볼트는 (내 볼트 경로)
```

상세는 `검색/README.md` · `palantir/` · `세팅/MCP 서버.md`를 봅니다.
