# 윈도우에서도 돼요?

**한 줄** — 됩니다. 단축키만 Cmd를 Ctrl로 읽고, 경로는 Windows 형식으로 잡으면 됩니다.

**확인되는 사실**
- 옵시디언 · Claude Code · 이 저장소 세팅 절차는 Windows에서도 동작합니다.
- START 0단계: 옵시디언은 https://obsidian.md 에서 Windows 설치 파일을 받습니다. Homebrew 분기는 macOS 전용입니다.
- 경로 예: `C:\Users\내이름\Documents\세컨브레인`, 저장소는 `git clone` 또는 ZIP으로 `%USERPROFILE%\Downloads\bottom-up`.
- 단축키: 문서의 `Cmd`는 Windows에서 `Ctrl`로 읽습니다.
- 검색 엔진(MCP) 설치는 OS별로 의존성이 다를 수 있습니다. 막히면 Issues에 OS·오류 메시지를 적어 올립니다.

**하는 법**
1. 옵시디언·Claude Code(Windows) 설치.
2. 저장소를 받은 뒤 폴더에서 `claude` 실행 → START.md대로 세팅.
3. 볼트 경로는 문제 시 영문 경로를 쓰면 단순합니다.
