# 노션이랑 뭐가 달라요?

**한 줄** — 노션은 클라우드 문서 위키에 가깝고, 이 가이드는 **내 컴퓨터 폴더의 마크다운 + 로컬 AI** 조합입니다.

**확인되는 사실**
- 노트 파일이 vault 폴더 안에 `.md`로 쌓입니다. Git·검색·Claude Code가 같은 폴더를 그대로 엽니다.
- 데이터가 기본적으로 내 디스크에 있습니다 (동기화를 따로 쓰지 않는 한).
- 노션에서 옮겨 올 때는 옵시디언 Importer 플러그인을 한 번 쓸 수 있습니다.

**이 가이드가 권하는 방식**
- 내 컴퓨터 폴더에 노트가 쌓이고, 같은 폴더를 AI가 열어 봅니다.
