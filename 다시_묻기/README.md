# 다시_묻기

「잘 몰라도 되는데 그냥 내가 정리한 파일을 AI한테 넣고 물어봐라」
「그렇게 학습하라」

이 폴더는 질문 하나에 답 파일 하나입니다. 답은 영상 · 블로그 · 노트에 정리된 문장으로 채웠습니다.

## 쓰는 법 셋

1. **Claude Code에서 그냥 묻습니다.** 저장소 폴더에서 `claude`를 켜고 질문합니다.
2. **웹 AI에 묶음 파일 하나를 올립니다.** [다시_묻기.md](../다시_묻기.md)를 ChatGPT · Gemini · NotebookLM에 올립니다. 재생성: `bash scripts/build_다시_묻기_bundle.sh`
3. **정말 모르겠으면 Issues.** [질문 올리기](https://github.com/netnox/bottom-up/issues/new?template=%EC%A7%88%EB%AC%B8.md)로 남깁니다.

## Claude가 답하는 법

1. 답 파일부터 읽는다.
2. 답 파일의 문장으로 답한다. 「」 안은 원문 그대로.
3. 짧게, 실행 중심으로.
4. 없으면 없다고 밝히고 Issues를 안내한다.
5. 한국어·일반 눈높이로 말한다.
